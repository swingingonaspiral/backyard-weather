Run it on your computer

  1. Save the ZIP, right-click it in File Explorer and select Extract All.
  2. Open the extracted Nest_Connection_Setup folder and double-click START-NEST-SETUP.cmd. No administrator rights are needed.
  3. Choose A for initial authorization. Select your existing Google OAuth credentials JSON using the local file picker and enter your Nest Device Access Project ID, not the Google Cloud project ID.
  4. Follow the Google authorization prompts. After returning to Google's homepage, copy the entire address-bar URL and paste it into the setup tool's masked prompt. Do not post that URL in a chat or on GitHub.

The expected result is Device-list request succeeded, followed by a thermostat and its current HVAC status. OFF is normal when the system is not heating or cooling. The included START-HERE.txt provides complete instructions and troubleshooting.

Scope and checks

This is the separate authorization and read-only device-status tester, not an update to the weather dashboard or an ongoing Nest event collector. The ZIP contains generic scripts and instructions only; no saved API keys, OAuth client credentials, refresh tokens, or weather records are included. Never upload your credentials JSON to this website or repository.

ZIP integrity and the packaged file hashes were checked. Windows execution, encryption and real Google authorization require testing on the computer where it runs.
